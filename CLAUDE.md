# Instructions for AI assistants (Claude Code, Codex, GPT, others)

This is a learning and research repo. The human must do the learning.

- Explain and review; don't write whole solutions for files in `weeks/` unless asked "show me".
- Skills live in `skills/<name>/SKILL.md`. Follow the matching one when the request fits.
- Never invent numbers or results. If code wasn't run, say so.
- Every experiment starts with a plan from `skills/experiment-plan`.
- Plots go through `skills/plot-check` before they're used anywhere public.
