# Weekly review

1. Read the current week folder in `weeks/` and its "Done when" checklist.
2. Check evidence: commits this week, files in `labnotes/`, tests passing (`pytest -q`).
3. For each subject say: shipped / partly / skipped, with the file that proves it.
4. Name one blocker and one change for next week. No catch-up debt.
