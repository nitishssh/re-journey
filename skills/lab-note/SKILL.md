# Lab note

1. Read `git log` and `git diff` for today, plus any plots in the changed folders.
2. Fill `labnotes/TEMPLATE.md` as `labnotes/<yyyy-mm-dd>-<slug>.md`.
3. Report numbers exactly as produced. Never round in my favour, never invent a result.
4. Include one "what I still don't understand" line. Empty is not allowed.
5. Keep it under 250 words.
