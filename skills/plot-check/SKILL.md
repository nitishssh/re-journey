# Plot check

Check, and fix in the plotting code (not the image):
- Axes labelled with units; title says what the plot shows, not what I hope.
- Y axis does not exaggerate differences (start at 0 for bars; say so if not).
- Error bars or shaded CI when there is more than one seed; state n.
- Baseline is drawn on the same axes.
- Colours readable in greyscale; legend does not cover data.
- The caption states the one conclusion the plot supports, and nothing more.
